Practicar en la aplicación ↗
Ramas del recorrido para mostrar al profesor
  • Modificar un confirmado: Mis pedidos → Modificar → cambiar plato → Guardar cambios → confirmar nuevamente. El cambio vuelve a borrador.
  • Cancelar: Mis pedidos → Cancelar pedido → Volver conserva el pedido; Sí, cancelar libera la porción.
  • Probar errores: apellido vacío, email duplicado, contraseña inválida, confirmación distinta, login sin registro y acceso administrativo como empleado.
  • Después de las 10:00 elegí un día futuro: el sistema respeta el corte de Argentina.
  • Para probar carga, vacío y error del catálogo: consultar el informe de revisión en docs/revision-final.md.
